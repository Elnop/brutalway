# Guides

Steps for one task at a time. If you have never used brutalway, start with [Getting started](../getting-started.md).

- [Use the checks in an existing project](existing-project.md): the checks one after the other, each turned on with its current errors recorded so main stays green
- [Move a project to the layout](move-to-the-layout.md): find the features, decide what goes down into `shared/` and what goes up, move in an order that keeps each pull request small, and hand the batches to an agent
- [Upgrade brutalway](upgrade.md): what to do after bumping a `@brutalway/*` package, and how to take the changes of a template
- [Work with Claude Code](claude-code.md): the hook that sends the errors back to the agent, in a template or in another project

To replace the todo list example with your own code, each template README has a section for it: [template-vite](../../templates/vite/README.md#starting-your-own-app), [template-next](../../templates/next/docs/guides/start-your-own-app.md), [template-react-native](../../templates/react-native/docs/guides/start-your-own-app.md), [template-fastify](../../templates/fastify/README.md#starting-your-own-api), [template-package](../../templates/package/README.md#starting-your-own-package).
