`npm run check` is `brutal-check` (`@brutalway/check`), which runs one script per check in a fixed order, keeps going after a failure and names the ones that failed. `format:check`, `repo`, `unused`, `secrets` and `exceptions` are new scripts. AGENTS.md and `docs/reference/commands.md` point to `docs/reference/verifications.md` instead of listing the tools.
