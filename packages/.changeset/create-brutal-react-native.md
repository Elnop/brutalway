`npm create brutal` offers a `react-native` stack, template-react-native on Expo and Expo Router. It takes the options of the vite stack that make sense on a phone: dark theme, TanStack Query, forms, i18n, React Compiler, analytics, component tests and coverage, plus `expo-go` to run the app in Expo Go instead of a development build. `app.json` takes the name of the project, and its identifier on the stores becomes `com.example.<name>`.
