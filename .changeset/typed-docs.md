The docs of a new project are split by what they are for. The README keeps the introduction, getting started and a list of links. `docs/guides/` holds the tasks (starting your own app, working with an agent, translations on vite, publishing on package), `docs/reference/` the commands, the layout, the endpoints on fastify and `verifications.md`, and `docs/concepts/` holds `architecture.md`. Turning off `claude-hook`, `release` or the fastify example removes the matching guide or reference page with its link.
